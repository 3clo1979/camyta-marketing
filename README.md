# CAMYTA Marketing

Website for CAMYTA Marketing Group.

## Cloudflare Workers

- Branch: main
- Build command: leave blank
- Deploy command: `npx wrangler deploy`
- Preview command, if requested: `npx wrangler versions upload`
- Repository root: default
- Static files: dist (configured in wrangler.jsonc)

Connect the repository through Cloudflare Workers and Pages, deploy, then add camyta.com as a custom domain.

## Contact and Rivet

Customer inquiries open an email draft to sales@camytagroup.com. Set up that address before accepting inquiries; the site does not create a mailbox or send email itself.

Rivet is currently a browser-local service guide. Live AI chat needs a separate server-side integration. Business examples are illustrative.
